# LuaHUD v0.2.0
## Features
New free drawing system with canvases. You can now draw elements wherever you want.

Also added new elements such as
- Rectangles
- Gradients (rectangle)
- Lines
- Circles
- Arcs

Also added `lh.measureText(text)` for measuring text width and height for your *precise* HUDs!

## API
### Added
- `lh.display.isChatOn`
- `lh.getTranslation(translationKey)`
- `attack` and `kill` events
- `lh.pos.chunk` `.localX`, `.localY` and `.localZ`
- `lh.biome` `.precipitation`, `.temperature`, `.waterColor`, `.skyColor`, `.foliageColor` and `.grassColor`
- `lh.perf.maxFps`
### Changed
- `lh.armor.armor` to `lh.armor.value`
- `lh.display` `.width` and `.height` to `windowWidth` and `windowHeight`.
- `lh.session.isMultiplayer` to `lh.session.multiplayer`
